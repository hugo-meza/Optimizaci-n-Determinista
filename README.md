# Optimización Determinista

Este repositorio contiene las prácticas y proyectos desarrollados durante el curso de **Optimización Determinista** impartido en el Tec de Monterrey durante el Semestre Febrero - Junio 2026.

## 📝 Descripción del Curso

La materia abarca los fundamentos teóricos y prácticos de la optimización matemática aplicada a la resolución de problemas. Entre los temas principales explorados en este repositorio se encuentran:

* Programación Lineal (Método Simplex, Dualidad, Análisis de Sensibilidad).
* Programación Entera y Mixta.
* Problemas de Redes (Transporte, Flujo Máximo, Ruta Más Corta).
